# Conference Manager для OJS 3.5: посібники користувача

Тут зібрано посібники для всіх, хто працює з плагіном «Менеджер конференцій» (Conference Manager) в Open Journal Systems 3.5. Плагін підходить для будь-якого закладу-організатора: закладу вищої освіти, фахового коледжу, ІППО, наукової установи, МАН, громадської організації чи хостинг-провайдера, який обслуговує кілька закладів.

English version: [../en/README.md](../en/README.md).

## Який посібник читати

Якщо ви керуєте сервером або всією інсталяцією OJS, почніть із посібника адміністратора сайту: без увімкненого плагіна, cron і черги частина функцій (нагадування, розсилки, автоматичне закриття прийому) не працюватиме. Якщо ви відповідаєте за конкретний захід у своєму журналі, читайте посібник менеджера: там описано все від першого налаштування до сертифікатів і звітів. Якщо вам доручили лише облік учасників і оплат, вам достатньо посібника реєстраційного менеджера. Посібник учасника можна дати авторам і слухачам як інструкцію або взяти з нього текст для інформаційного листа. Посібник про пресети потрібен тим, хто готує типові налаштування для свого закладу чи для інших.

## Основні поняття

- **Журнал (контекст)** в OJS для плагіна означає один заклад-організатор. Дані різних журналів одного сайту не перетинаються.
- **Видання** означає один конкретний захід: конференцію 2027 року, літню школу, вебінар. Кожне видання має свої дати, категорії учасників, тарифи, правила оплати, учасників і документи.
- **Профіль закладу** містить назву, реквізити, підписантів, рахунки й тексти про персональні дані. Ці дані потрапляють у рахунки, сертифікати й на публічні сторінки.
- **Профіль юрисдикції** вмикає національні правила. Профіль «Україна» додає ЄДРПОУ, казначейські рахунки, свідоцтва про підвищення кваліфікації й експорт для «Вектора». Профіль «Без національних правил» підходить для організаторів з інших країн.

## Доступність

Публічні сторінки плагіна (сторінка заходу, програма, реєстрація, кабінет учасника, документи, «Майбутні заходи») і екрани менеджера відповідають WCAG 2.1 рівня AA за автоматичною перевіркою axe: серйозних і критичних порушень немає, перевірка виконується в CI на кожну зміну. Усе, що робиться мишею, можна зробити й клавіатурою: доповідь у конструкторі програми переносять у сесію також списком «Перемістити до». Після переходу між екранами менеджера фокус переходить на заголовок нового екрана. Ручну перевірку з програмою читання з екрана варто провести з пілотними закладами.

## Поточні обмеження

- Розкладу програми із залами, сесіями й часом ще немає. Є статична програма: прийняті доповіді за секціями й формою участі.
- Онлайн-оплати карткою немає. Плагін виставляє рахунки й показує інструкції, а оплату записує менеджер.
- Повернення коштів плагін не робить: переплату менеджер вирішує вручну.
- Експорт у XLSX потребує розширення PHP `zip`. Без нього доступний CSV.
- Нагадування, розсилки, масові рішення й пакетна видача сертифікатів потребують планувальника й черги OJS.
