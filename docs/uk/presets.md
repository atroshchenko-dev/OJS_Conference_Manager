# Пресети: типові налаштування заходу

Цей посібник для закладів, які хочуть швидко налаштовувати свої заходи однаково, і для спільноти, яка готує типові налаштування для інших. Пресет описує одним файлом, яким буде нове видання: тип заходу, режими, категорії учасників, тарифи, правила оплати й налаштування сертифікатів. Менеджер журналу обирає пресет у майстрі «Перше налаштування» (див. [посібник менеджера](manager.md#як-пройти-перше-налаштування)).

## Що таке пресет

Пресет є файлом JSON. Майстер показує менеджеру пресети, що підходять до профілю юрисдикції його закладу, спершу для його типу закладу, і створює за обраним пресетом видання з усіма налаштуваннями. Після створення все можна змінити вручну, а сам пресет на вже створене видання більше не впливає.

**Суми у вбудованих пресетах є лише прикладами.** Після створення видання обов'язково перевірте й замініть їх сумами свого закладу.

## Вбудовані пресети

| Код | Для чого |
|---|---|
| `ua-university-private` | приватний заклад вищої освіти в Україні |
| `ua-university-state` | державний чи комунальний заклад вищої освіти в Україні |
| `ua-ippo` | інститут післядипломної педагогічної освіти |
| `ua-research-institute` | наукова установа |
| `ua-man` | Мала академія наук |
| `generic-conference` | конференція будь-якого організатора без національних правил |

Що саме створює кожен пресет, видно на його картці в майстрі. Майстер називає пресети «типовими наборами».

## Де лежать пресети

- **У пакеті плагіна:** каталог `presets/`. Тут вбудовані пресети. Вони оновлюються разом із плагіном, тому власні файли сюди не кладіть.
- **На сервері, без зміни пакета:** каталог `{files_dir}/conferenceManager/presets/`, де `{files_dir}` означає каталог файлів OJS із `config.inc.php`. Сюди адміністратор сайту кладе власні пресети закладу чи спільноти. Оновлення плагіна їх не зачіпає.

Пресети з обох каталогів доступні в усіх журналах сайту, де ввімкнено плагін, якщо підходять за типом закладу й юрисдикцією.

## Формат файлу

Файл у кодуванні UTF-8 з одним об'єктом JSON. Поля:

| Поле | Що означає |
|---|---|
| `schema` | Версія формату. Зараз завжди `1`. |
| `code` | Код пресету: малі латинські літери, цифри й дефіси. Має бути унікальним серед усіх пресетів сайту. |
| `name` | Назва для майстра мовами інтерфейсу: `{"uk": "…", "en": "…"}`. |
| `description` | Короткий опис для картки в майстрі, у тому самому вигляді: `{"uk": "…", "en": "…"}`. |
| `jurisdiction` | `"UA"`, `"generic"` або `null`, якщо пресет підходить для будь-якої юрисдикції. |
| `institutionTypes` | Список типів закладу, для яких показувати пресет: `university`, `college`, `ippo`, `research_institute`, `man`, `ngo`, `other`. |
| `edition` | Налаштування видання (див. нижче). |
| `categories` | Список категорій учасників. |
| `tariffs` | Список тарифів. |
| `paymentRules` | Список правил оплати. |
| `certificates` | Налаштування сертифікатів. |

Порожній список `institutionTypes` означає, що пресет підходить для будь-якого типу закладу.

### `edition`

| Поле | Значення |
|---|---|
| `eventType` | `conference`, `seminar`, `webinar`, `school`, `round_table`, `contest`, `other` |
| `submissionMode` | `none` (без подань, лише слухачі), `abstracts` (тези), `abstracts_and_papers` (тези, потім повні тексти) |
| `publicationMode` | `none` (без збірника), `ojs_issue` (випуск у цьому журналі), `external` (зовнішній збірник) |
| `format` | `in_person`, `online`, `hybrid` |
| `reviewMode` | режим рецензування, як у формі видання (необов'язково) |
| `hours` | години для свідоцтва про підвищення кваліфікації, ціле число (необов'язково) |
| `ectsX100` | кредити ЄКТС, помножені на 100: `20` означає 0,2 кредиту (необов'язково) |

Назву, адресу й дати видання пресет не задає: їх менеджер вводить на третьому кроці майстра.

### `categories`

Кожна категорія: `{"code": "…", "requiresProof": true|false, "name": {"uk": "…", "en": "…"}}`.

- `code`: код категорії, за яким на неї посилаються тарифи й правила оплати.
- `requiresProof`: чи потрібне підтвердження (довідка, студентський квиток). Якщо поле не вказано, підтвердження не потрібне.
- `name` можна не вказувати для вбудованих кодів, тоді назва береться з плагіна: `own_staff`, `partners`, `other_faculty`, `students`, `foreign`, `teachers_region`, `teachers_other`, `heads`, `researchers`, `young_researchers`, `pupils`, `teachers_supervisors`, `guests`, `members`, `general`. Для власних кодів `name` обов'язковий.

### `tariffs`

Кожен тариф: `{"category": "…", "material": "…", "pricing": "…", "amount": "…", "currency": "…"}`.

- `category`: код категорії зі списку `categories`.
- `material`: `abstract` (тези), `paper` (стаття), `listener` (участь слухача), `any` (будь-який матеріал).
- `pricing`: `flat` (фіксована сума) або `per_page` (за сторінку). Участь слухача завжди `flat`.
- `amount`: сума рядком із двома знаками після крапки, наприклад `"400.00"`. `"0.00"` означає безкоштовно.
- `currency`: код валюти ISO 4217, наприклад `"UAH"`.

### `paymentRules`

Кожне правило: `{"category": "…" або null, "mode": "…"}`.

- `category`: код категорії або `null` для правила «Усі інші категорії». Правило з `null` може бути лише одне.
- `mode`: `free`, `bank_transfer`, `treasury_transfer`, `external_organizer`, `external_link`.

Правила, яким потрібен рахунок отримувача, майстер створює лише тоді, коли в профілі закладу є активний рахунок. Інакше він повідомить менеджеру, що треба додати рахунок і створити правило пізніше на сторінці **Оплата**. Правило `external_link` майстер не створює, бо в пресеті немає адреси сторінки оплати: менеджер додає його на сторінці **Оплата**.

### `certificates`

`{"professionalDevelopment": true|false, "vector": true|false}`

- `professionalDevelopment`: заклад видає свідоцтва про підвищення кваліфікації (має сенс для профілю `UA`; обсяг у годинах менеджер вказує у виданні).
- `vector`: увімкнути вивантаження для платформи «Вектор». Якщо профіль юрисдикції закладу такого експорту не має, майстер його не вмикає й повідомляє про це.

## Приклад

Пресет для конференції фахового коледжу в Україні: тези, збірник у журналі, змішаний формат, три категорії, оплата банківським переказом, студенти безкоштовно.

```json
{
  "schema": 1,
  "code": "example-college-conference",
  "name": {
    "uk": "Студентська конференція коледжу",
    "en": "College student conference"
  },
  "description": {
    "uk": "Тези, збірник у журналі, змішаний формат. Здобувачі освіти безкоштовно, інші за банківським переказом.",
    "en": "Abstracts, proceedings in the journal, hybrid format. Students free, others by bank transfer."
  },
  "jurisdiction": "UA",
  "institutionTypes": ["college"],
  "edition": {
    "eventType": "conference",
    "submissionMode": "abstracts",
    "publicationMode": "ojs_issue",
    "format": "hybrid"
  },
  "categories": [
    { "code": "students", "requiresProof": true },
    { "code": "own_staff", "requiresProof": true },
    {
      "code": "school_teachers",
      "requiresProof": false,
      "name": { "uk": "Вчителі закладів загальної середньої освіти", "en": "School teachers" }
    }
  ],
  "tariffs": [
    { "category": "students", "material": "abstract", "pricing": "flat", "amount": "0.00", "currency": "UAH" },
    { "category": "own_staff", "material": "abstract", "pricing": "flat", "amount": "200.00", "currency": "UAH" },
    { "category": "school_teachers", "material": "abstract", "pricing": "flat", "amount": "300.00", "currency": "UAH" },
    { "category": "school_teachers", "material": "listener", "pricing": "flat", "amount": "100.00", "currency": "UAH" }
  ],
  "paymentRules": [
    { "category": "students", "mode": "free" },
    { "category": null, "mode": "bank_transfer" }
  ],
  "certificates": {
    "professionalDevelopment": false,
    "vector": false
  }
}
```

## Як додати свій пресет

1. Візьміть за основу приклад вище або вбудований пресет із каталогу `presets/` пакета.
2. Змініть `code` на власний, унікальний. Радимо називати файл так само, як код, наприклад `example-college-conference.json`.
3. Заповніть `name` і `description` обома мовами, оберіть `jurisdiction` і `institutionTypes`.
4. Перевірте синтаксис JSON будь-яким валідатором: зайва кома чи лапка робить файл недійсним.
5. Передайте файл адміністратору сайту. Він кладе його в `{files_dir}/conferenceManager/presets/` на сервері (каталог можна створити через файловий менеджер хостингу чи FTP).
6. Адміністратор відкриває **Конференції: огляд сайту** і в блоці **Типові набори** перевіряє, скільки наборів доступно і чи немає файлу в списку помилок.
7. Менеджер журналу відкриває **Майстер налаштування** на сторінці «Конференції» і бачить новий пресет у списку.

### Якщо пресета немає в майстрі

- Файл із помилками в майстрі не пропонується. Сторінка **Конференції: огляд сайту** в блоці **Типові набори** називає файл і помилку: наприклад, неправильне значення поля, повторний `code` або тариф із кодом категорії, якої немає в `categories`.
- Перевірте `institutionTypes`: для перелічених типів закладу пресет іде першим, для інших показується на сірому тлі. Тип закладу задано в профілі закладу, а в майстрі його можна змінити на першому кроці.
- Перевірте `jurisdiction`: пресет з `"UA"` не показується журналу з профілем «Без національних правил», і навпаки. `null` підходить для будь-якого.

## Як поділитися пресетом зі спільнотою

Якщо ваш пресет буде корисним іншим закладам, запропонуйте його до пакета через репозиторій проєкту (див. `CONTRIBUTING.md`). Перед цим:

- приберіть назви, реквізити й інші дані, що стосуються лише вашого закладу;
- залиште суми як приклад і так і напишіть в описі;
- переконайтеся, що назви й описи є українською та англійською.
