# Журнал змін

Формат — [Keep a Changelog](https://keepachangelog.com/uk/1.1.0/), версії — `major.minor.revision.build`, як вимагає OJS.

## [0.2.0.0] — 2026-11-14

### Додано
- Видання (EDN-01…05, EDN-09 без тарифів, EVT-01…03): таблиці `conf_editions`, `conf_edition_settings`; типи подій із режимами подань і публікації за замовчуванням (вебінар — без подань і без збірника); вікна прийому з часовим поясом видання (дати зберігаються в UTC); перевірка послідовності дат, ISBN-13, адреси видання, переходів статусу.
- Режим публікації `ojs_issue` створює неопублікований випуск OJS (один на видання); `external` вимагає посилання на збірник; `none` — без збірника.
- REST API видань: `GET/POST /editions`, `GET/PUT/DELETE /editions/{id}`, `POST /editions/{id}/copy`, `GET /editions/options`. Видання з учасниками, рахунками або поданнями не видаляється (409).
- Схема решти модулів (крок `0003_conference_core`): учасники, участі, категорії й тарифи, рахунки й позиції, підтвердження оплати, платіжні події, зали й сесії, шаблони сертифікатів і сертифікати, лічильники номерів, розсилки, старі адреси, партнери видання, правила оплати.
- Групи користувачів «Учасник» (роль Reader, самореєстрація) і «Реєстраційний менеджер» (роль Assistant) у кожному контексті (REG-01), ідемпотентно.
- Властивості публікації `conferenceEditionId`, `presentationType`, `pageCount`.

### Змінено
- API-контролер перейменовано на `ConferenceApiController`; модулі додають маршрути через `RouteModule`.

## [0.1.0.0] — 2026-11-14

### Додано
- Каркас плагіна `conferenceManager` для OJS 3.5 (`GenericPlugin`, lazy-load), локалі `uk` і `en`.
- Міграції кроками (`classes/Migrations/Steps`), що знаходяться з файлової системи й ідемпотентні; таблиця `conf_schema_steps`; `upgrade.xml`, щоб міграції виконувалися під час оновлення пакета.
- Таблиці профілю закладу: `conf_institutions`, `conf_institution_settings`, `conf_signers`, `conf_signer_settings`, `conf_payment_accounts`, `conf_audit_log`.
- Профіль закладу (INS-01…03, 05…07): форма в налаштуваннях плагіна, REST API, імпорт / експорт JSON, журнал аудиту.
- Профілі юрисдикції `generic` і `UA` та хук `ConferenceManager::jurisdictions` для сторонніх профілів.
- CI: lint, перевірка локалей і шарів, PHPStan, PHPUnit (PHP 8.2–8.4), пакування, встановлення й оновлення в OJS 3.5.0-5/3.5.0-6 на MariaDB і PostgreSQL.
