# Дизайн плагіна Conference Manager

Плагін не має власного «бренду». Він є частиною OJS і має виглядати як OJS:
у редакційній частині (бекенд) як інтерфейс OJS 3.5, на публічних сторінках як
тема журналу, у якому працює. Кольори й форми задані токенами (CSS-змінні
`--cm-*`). Сторінки використовують лише назви токенів, не сирі значення.

Файли токенів:

| Де | Файл | Звідки значення |
|---|---|---|
| Редакційна частина | `css/backend-tokens.css` | бібліотека інтерфейсу OJS 3.5 (`lib/ui-library/tailwind.config.js`, гілка `stable-3_5_0`) |
| Публічні сторінки | `css/public.css` (блок `:root`) | тема журналу: колір `baseColour` теми Default та її дочірніх тем |

## 1. Редакційна частина

### Шрифти й розміри

Свого шрифту немає. Текст успадковує шрифт OJS (Noto Sans) і його розміри:
14px для полів і таблиць (`.875rem`), 13px для підказок (`.8125rem`), 12px для
дрібних позначок (`.75rem`). Заголовки сторінок малює OJS.

### Кольори

| Токен | Значення | Роль |
|---|---|---|
| `--cm-primary` | `#006798` | кнопки, посилання, активні вкладки й кроки, рамка фокуса (OJS primary) |
| `--cm-primary-surface` | `#eef6fb` | виділений рядок, запущена масова дія, місце для перетягування |
| `--cm-on-primary` | `#fff` | текст на `--cm-primary` |
| `--cm-heading` | `#01354f` | текст на тонованих позначках |
| `--cm-text` | `#222` | основний текст |
| `--cm-text-secondary` | `#505050` | підказки, метадані, порожні стани |
| `--cm-bg` | `#fff` | панелі, таблиці, форми |
| `--cm-bg-muted` | `#f7f7f7` | заголовки таблиць, вкладені панелі, позначки |
| `--cm-border` | `#ddd` | рамки панелей і таблиць |
| `--cm-border-subtle` | `#eee` | роздільники рядків усередині панелі |
| `--cm-border-strong` | `#bbb` | позначки, пунктирні зони |
| `--cm-border-field` | `#767676` | поля вводу, які не стилізує OJS (3:1 на білому) |
| `--cm-error` / `-surface` | `#d00a0a` / `#fdf2f2` | помилки форм, невдалі дії (OJS attention) |
| `--cm-negative` / `-text` / `-surface` | `#d00a6c` / `#a40045` / `#fff5f9` | конфлікти й попередження, що блокують роботу (OJS negative) |
| `--cm-success` | `#00b24e` | лише рамки й маркери, не текст: 2,8:1 (OJS success) |
| `--cm-success-text` / `-surface` | `#006c35` / `#e9f6ee` | успішні повідомлення |
| `--cm-warning` / `-text` / `-surface` | `#b45309` / `#5c4400` / `#fff4ce` | чернетки, попередження |

Кнопки, поля, вкладки й списки помилок беруть класи OJS (`pkpButton`,
`pkpFormField__input`, `pkp_form_error_list`), а не власні. Нову кнопку чи поле
слід робити так само.

### Форма й глибина

- Радіус `--cm-radius: 4px` (як в OJS), для «таблеток» `--cm-radius-pill`.
- Тіней немає. Панель має рамку `1px solid var(--cm-border)` або `--cm-ring`.
- Відступи кратні 4px (`.25rem`, `.5rem`, `.75rem`, `1rem`, `1.5rem`).

## 2. Публічні сторінки

Шрифт, заголовки, посилання, ширина сторінки й поля форм належать темі журналу.
Плагін додає лише свої блоки (умови участі, програма, кабінет, рахунки,
перевірка сертифіката) і фарбує їх токенами.

| Токен | Типове значення | Роль |
|---|---|---|
| `--cm-accent` | колір теми, інакше `#1e6292` | головні кнопки, рамки сесій програми |
| `--cm-on-accent` | `#fff` або `#222222` | текст на кнопці, обирається за контрастом |
| `--cm-accent-text` | колір теми, затемнений до 4,5:1 | акцент як текст |
| `--cm-accent-surface` | 8 % кольору теми на білому | тоновані блоки |
| `--cm-success` / `-surface` | `#1a7f37` / `#e9f6ee` | прийом заявок відкрито, сертифікат дійсний, оплату прийнято |
| `--cm-danger` / `-surface` | `#b00020` / `#fdf3f3` | помилки, відкликано, відхилено |
| `--cm-warning` / `-surface` | `#8a6100` / `#fff4ce` | чернетка, лист очікування, інструкції з оплати |
| `--cm-muted` | `#555` | підказки |
| `--cm-border`, `--cm-border-strong`, `--cm-border-field` | `#ddd`, `#999`, `#767676` | рядки таблиць, рамки, поля |
| `--cm-surface` | `#f5f5f5` | заголовки таблиць, позначки |
| `--cm-radius` | `3px` | кнопки й позначки, як у темі Default |

Як працює колір теми: на кожній публічній сторінці плагін читає параметр
`baseColour` активної теми (Default, Manuscript та інші дочірні теми Default)
і додає вбудований стиль із чотирма токенами акценту
(`classes/Domain/Site/ThemeAccent.php`). Теми без цього параметра (Health
Sciences, Classic) отримують типовий синій `#1e6292`. Дочірня тема закладу
може задати будь-який `--cm-*` у своєму CSS на `:root` або `.cmEdition`.

Стани (успіх, помилка, попередження) від теми не залежать: зелений завжди
означає «відкрито / дійсно», червоний «помилка / відкликано».

## 3. Типи сесій програми

Однакові в редакційній частині й на сайті:

| Токен | Значення | Тип |
|---|---|---|
| `--cm-session-plenary` | `#6a3d9a` | пленарне засідання |
| `--cm-session-poster` | `#00796b` | стендова сесія |
| `--cm-session-seminar` | `#b45309` | семінар, майстер-клас |
| `--cm-session-break` | `#9e9e9e` (сайт: 20 % чорного) | перерва |
| інші типи | `--cm-primary` / `--cm-accent` | секційне засідання |

## 4. Документи для друку

Рахунки, сертифікати, програма в PDF і книга тез мають власні шаблони
(`templates/invoice`, `templates/certificate`, `templates/frontend/programPdf.tpl`).
Генератори PDF не розуміють CSS-змінних, тож кольори там задані прямо.
Ці документи чорно-білі з одним темно-синім акцентом і не мають залежати
від теми сайту.

## 5. Правила

- Нові кольори не додаються «за місцем»: спершу токен із роллю тут, потім код.
- Текст має контраст не менше 4,5:1 до фону, рамки полів не менше 3:1.
- Жодних градієнтів, тіней, власних шрифтів чи емодзі замість іконок:
  плагін має бути непомітною частиною OJS.
- Без прив'язки до конкретного закладу: кольори закладу приходять з теми його
  журналу.
