# Conference Manager для OJS 3.5

Відкритий плагін для проведення конференцій, шкіл, семінарів та інших наукових і освітніх заходів на базі **Open Journal Systems 3.5 LTS**. Призначений для будь-якого закладу-організатора: ЗВО (державних, комунальних, приватних), фахових коледжів, ІППО, наукових установ, МАН, громадських організацій і хостинг-провайдерів, зокрема для багатозакладних інсталяцій, де кожен заклад має свій контекст.

Нічого в коді не прив'язано до конкретного закладу. Усе, що стосується організатора, налаштовується в **профілі закладу** кожного контексту, а національні норми (ЄДРПОУ, казначейські рахунки, сертифікати підвищення кваліфікації, «Вектор») вмикаються **профілем юрисдикції** `UA`. Профіль `generic` вимикає їх для організаторів з інших країн.

> Статус: **0.32.1.0**. Плагін охоплює весь цикл заходу: профіль закладу й профілі юрисдикції, видання й публічні сторінки, подання з анкетою доповідача, рецензування (голосування комітету, двофазне, вибір подань рецензентами), оргвнески, промокоди й лист очікування, рахунки з PDF, групові рахунки, онлайн-оплату карткою через LiqPay, квитанції й повернення, програму з конструктором розкладу й персональною програмою, QR-квитки й облік присутності на сесіях, сертифікати й свідоцтва про підвищення кваліфікації, збірник тез, звіти, персональні дані, перенесення архіву OCS і режим «сайт конференцій» для публічної частини журналу.
>
> Сторінки «Майбутні заходи» (`/index/conference/upcoming`) і «Конференції: огляд сайту» працюють, коли плагін увімкнено на рівні сайту. На сайті з одним журналом плагін робить це сам; на кількох журналах це робить адміністратор сайту («Адміністрування → Налаштування сайту → Плагіни»). Автоматичне закриття прийому працює через планувальник OJS (cron `php lib/pkp/tools/scheduler.php run` або веб-запуск завдань).

## Встановлення

1. Завантажте пакет `conferenceManager-<версія>.tar.gz` з релізів.
2. OJS: **Налаштування → Вебсайт → Плагіни → Завантажити новий плагін**.
3. Увімкніть «Менеджер конференцій» у потрібному контексті й відкрийте **Профіль закладу-організатора** (кнопка біля плагіна).
4. Відкрийте розділ **Конференції**. Поки в журналі немає видань, там запускається **майстер першого налаштування**: він створить перше видання з типовим набором для вашого типу закладу.

Посібники для адміністратора сайту, менеджера журналу, реєстраційного менеджера, рецензента й учасників українською та англійською: [docs/uk](docs/uk/README.md), [docs/en](docs/en/README.md).

Оновлення — так само, через «Оновити» в списку плагінів. Пакет містить `upgrade.xml`, тому міграції виконуються й під час оновлення, без доступу до shell. Перед оновленням зробіть резервну копію бази й `files_dir`.

Вимоги: OJS 3.5.0-5 або новіший у гілці 3.5, PHP 8.2+, MySQL/MariaDB або PostgreSQL.

## Що вміє плагін

- **Профіль закладу** для кожного контексту (INS-01, 05, 06): повна й скорочена назва кількома мовами, тип закладу, форма власності, ідентифікатор юрособи, адреса, контакти, тексти про персональні дані й строки зберігання.
- **Підписанти** (INS-02) з призначенням на документи: рахунок і сертифікати різних типів.
- **Платіжні реквізити** (INS-03): кілька рахунків (банківський, казначейський, співорганізатора), перевірка IBAN, шаблон призначення платежу зі змінними.
- **Профілі юрисдикції** (INS-06, розд. 7.8): `generic` і `UA` (ЄДРПОУ з контрольним розрядом, український IBAN, казначейство, код ЄДЕБО). Інші плагіни можуть додати свій профіль через хук `ConferenceManager::jurisdictions`.
- **Імпорт і експорт профілю** у JSON (INS-07) для швидкого налаштування нових контекстів.
- **Журнал аудиту** змін профілю.
- **REST API**: `/{context}/api/v1/conference/institution` (GET, PUT), `…/institution/export`, `…/institution/import`, `…/jurisdictions`; `…/editions` (GET, POST), `…/editions/{id}` (GET, PUT, DELETE), `…/editions/{id}/copy`, `…/editions/options`. Дати видань приймаються як місцевий час видання (`2027-05-20 09:00`) або з зсувом (`…Z`, `+02:00`), повертаються в UTC і окремо в місцевому часі (`local`). Доступ: менеджер контексту й адміністратор сайту. `…/submissions/{id}/registration` (GET, PUT) — анкета доповідача; доступ також для автора подання.
- **Сайт конференцій** (0.32): режим публічної частини журналу, у якому тексти OJS говорять про конференцію й збірник матеріалів замість журналу й випуску («Про конференцію», «Поточний збірник», «Архів матеріалів», «Оргкомітет»); сторінка `/{журнал}/conference` зі списком заходів, блок «Найближчі заходи» на головній, пункт меню «Конференції» як тип пункту навігації OJS. Майстер першого налаштування вмикає режим сам; перемикач — у розділі «Публічна частина» на сторінці «Конференції».
- **Перенесення архіву OCS** (0.31): скрипт `tools/ocs-migration/migrate.sh` відновлює дамп OCS 2.3.6, переносить опубліковані доповіді й файли через OJS 3.4 до OJS 3.5 і готує карту старих адрес. Перевірено на копії OCS закладу-партнера (1059 доповідей, усі старі адреси зіставлено). Плагін вмикається на рівні сайту сам на інсталяції з одним журналом.
- **Огляд інтерфейсу** (0.30): коротший рядок видання, окремий рядок інструментів для всього журналу, таблиця учасників без горизонтальної прокрутки, пошук і сторінки в сертифікатах, «Мій кабінет» замість повторної реєстрації, попередні рахунки згорнуто.
- **Онлайн-оплата карткою** (0.29): власний мерчант-рахунок закладу в LiqPay (API v3), режим правила оплати «Оплата карткою онлайн», кнопка в кабінеті, зарахування лише за підписаним повідомленням або запитом стану, щогодинна перевірка незавершених оплат, хук `ConferenceManager::paymentGateways` для інших сервісів. За замовчуванням вимкнено.
- **Сумісність із TIB Conference** (0.28): дати, місце й формат заходу синхронізуються між формою випуску OJS і виданням в обидва боки, якщо плагін TIB Conference встановлено.
- **Вибір подань рецензентами** (0.27): сторінка рецензента з поданнями без імен авторів, вибір «дуже хочу / можу / не хочу / конфлікт», запропонований розподіл і призначення одним кліком, листи-запрошення.
- **Промокоди й лист очікування** (0.26): знижка відсотком чи сумою з лімітом і строком, ліміт очних місць для слухачів, черга без рахунку й автоматичне надання звільненого місця.
- **QR-квиток і персональна програма** (0.25): вхідний квиток із підписаним кодом, сторінка відмітки на вході, кнопка «До моєї програми» й iCal персональної програми.
- **Присутність на сесіях** (0.24): позначки й імпорт звіту Teams, Zoom чи Google Meet для окремої сесії, модератор позначає присутніх сам, години свідоцтва з відвіданих семінарів.
- **Партнери, доступність, копіювання, звіти** (0.20–0.23): співорганізатори й партнери з логотипами на публічній сторінці; перевірка WCAG 2.1 AA (axe-core) у CI; копіювання видання разом із категоріями, тарифами, правилами оплати, залами й налаштуваннями рецензування; огляд сайту з поданнями, оплатами й сертифікатами за журналами; звіти за секціями, формами, установами й країнами; стан планувальника; листи-запрошення в PDF.
- **Видання й публічні сторінки** (0.2–0.3): форма видань для менеджера, сторінка видання з schema.org/Event, «Майбутні заходи» сайту, автоматичне закриття прийому.
- **Майстер подання** (0.4): крок «Участь у конференції» з анкетою доповідача й згодою, блокування подання поза вікном прийому, учасники з авторів, підтвердження участі співавторами за одноразовим посиланням.
- **Оргвнески й учасники** (0.5): категорії учасників із типовими наборами, тарифна матриця з розрахунком у цілих копійках, реєстрація слухачів, кабінет учасника `/{context}/conference/my`, реєстр із фільтрами й CSV, скасування участі з обробкою рахунків.
- **Оплата й рахунки** (0.6): режими оплати й правила «категорія → режим», рахунки слухачам після реєстрації й доповідачам після прийняття, номер без пропусків і код платежу, PDF із банківського чи казначейського шаблону (журнал може змінити шаблон без коду), сума прописом, часткова оплата, звільнення від оплати, рахунки в кабінеті учасника.
- **Рішення щодо подань** (0.8): рішення «Прийняти» з типом виступу (усна, стендова, онлайн, заочна), після яких подання йде на редагування й до випуску заходу, а доповідач отримує рахунок за тарифом типу; масові рішення через чергу OJS з окремим листом кожному автору; зміна типу виступу після рішення з перерахунком рахунку; панель «Участь у заході» на картці подання.
- **Квитанції й журнал платежів** (0.7): квитанції PDF/JPG/PNG у кабінеті з перевіркою вмісту й приватним зберіганням, черга перевірки для реєстраційного менеджера з листом платнику, журнал платежів видання, що лише доповнюється, фільтр реєстру за оплатою, неповнолітні учасники зі згодою батьків або законного представника.
- **Групи, запрошення, повернення** (0.19): один рахунок від організації для кількох учасників, запрошені доповідачі й гості з листом і нульовими рахунками, запис повного чи часткового повернення коштів з приміткою в експорті для бухгалтерії.
- **Рецензування** (0.18): голосування комітету з коментарями й підсумком на сторінці рішень, попередження про конфлікт інтересів за місцем роботи, двофазне рецензування (тези, рішення «Тези прийнято — подайте повний текст», повний текст) з окремими формами рецензії для кожного етапу.
- **Збірник тез** (0.17): PDF з тезами прийнятих доповідей у порядку програми, секцій або назв, з титулом, зворотом (ISBN, УДК), змістом, наскрізною нумерацією й покажчиком авторів; формат A5 або A4 з дзеркальними полями.
- **Старі адреси OCS** (0.16): зіставлення доповідей OCS зі статтями журналу з CSV, налаштовувані шаблони старих адрес, карта переадресацій 301 для nginx і Apache і запасна переадресація самим плагіном. Посібник з перенесення архіву OCS: [docs/uk/ocs-migration.md](docs/uk/ocs-migration.md).
- **Конструктор програми** (0.15): зали й сесії, перетягування прийнятих доповідей у сесії з автоматичним часом, попередження про зайнятий зал і доповідача у двох сесіях одночасно. - **Перше налаштування й типові набори** (0.14): майстер у розділі «Конференції» створює видання з категоріями, тарифами, правилами оплати й налаштуваннями документів за типовим набором (пресетом) для типу закладу. Шість наборів у пакеті (приватний і державний ЗВО, ІППО, наукова установа з ГО, учнівська конференція, організатор з-за меж України); заклади й спільнота додають власні JSON-файли в `{files_dir}/conferenceManager/presets/` без зміни пакета ([формат](docs/uk/presets.md)). Посібники за ролями українською й англійською. CI перевіряє шість типових конфігурацій закладів (розділ 17.5 плану).

- **Український профіль документів** (0.11): свідоцтво про підвищення кваліфікації за п. 13 постанови № 800 (години, кредити ЄКТС, результати навчання, часткові кваліфікації, ЄДРПОУ закладу) з англійською версією; публічний реєстр виданих свідоцтв; відкликання й перевипуск з новим номером; експорт для платформи «Вектор» (за замовчуванням вимкнено); пакетна видача через чергу OJS; подяки рецензентам; реквізити платника-організації з ЄДРПОУ, а РНОКПП лише за вмиканням.
- **Присутність і сертифікати** (0.10): позначки присутності в реєстрі й імпорт звіту Teams, Zoom чи Google Meet з порогом у хвилинах; шаблони сертифікатів п'яти видів зі змінними й попереднім переглядом; номери за серією й роком; видача за правилами (слухач за присутністю, доповідач за прийнятою доповіддю, заочний автор після публікації); PDF A4 альбомний, що не змінюється після видачі; QR-код і публічна сторінка перевірки; сертифікати в кабінеті учасника.
- **Розсилки, нагадування й звіти** (0.9): перевиставлення рахунку з перенесенням сплаченої суми; публікація лише після оплати; експорт для бухгалтерії в CSV і XLSX з власними колонками; розсилки учасникам за умовами через чергу OJS; автоматичні нагадування про оплату, повний текст і початок заходу; підсумки заходу; версії тексту згоди й журнал дій.

## Обмеження

- Нагадування надсилає планувальник OJS: потрібен `cron` з `php lib/pkp/tools/scheduler.php run` або веб-запуск завдань. Нагадування за замовчуванням вимкнені.
- Масові рішення й розсилки виконує черга OJS (після веб-запитів або `php lib/pkp/tools/jobs.php work`).
- XLSX потребує розширення PHP `zip`; без нього доступний CSV.
- Повернення коштів плагін лише записує: гроші повертає бухгалтерія, а онлайн-оплату карткою — сам заклад у кабінеті LiqPay.
- Картка подання OJS 3.5 на ширині телефона прокручується вбік (поведінка самого OJS).

## Розробка

```bash
composer install
vendor/bin/phpunit                 # юніт- і інтеграційні тести (SQLite)
php ci/check-locales.php           # ключі локалей uk/en збігаються
php ci/check-layers.php            # правила шарів (Domain без залежностей від OJS)
vendor/bin/phpstan analyse         # рівень 8 для доменного шару

# Справжній OJS 3.5 у Docker: встановлення → оновлення з новою міграцією → API
ci/integration/start-ojs.sh mariadb   # або postgres
ci/integration/run.sh
ci/integration/api-smoke.sh
```

Структура й правила шарів описано в [docs/architecture.md](docs/architecture.md). Що перевірено на коді OJS 3.5.0-6 і чим реальність відрізняється від ескізів плану — у [docs/ojs-3.5-verification.md](docs/ojs-3.5-verification.md).

## English

**Conference Manager** turns OJS 3.5 into a platform for conferences, schools and seminars for any organizing institution. Organizer details live in a per-context **institution profile**; national rules are a switchable **jurisdiction profile** (`UA` built in, `generic` for everyone else, more via the `ConferenceManager::jurisdictions` hook). Status: **0.32.1.0**. Version 0.32.1 aligns the look with OJS: back-office pages use the colours of the OJS 3.5 interface through design tokens, and public pages take their main colour from the journal theme (see [DESIGN.md](DESIGN.md)). Version 0.32 adds a conference-site mode for a journal's public pages: OJS texts speak of the conference and its proceedings instead of the journal and its issues, `/{journal}/conference` lists the journal's events, the home page shows upcoming events and a "Conferences" navigation menu item type is available; the setup wizard turns the mode on. Version 0.31 adds `tools/ocs-migration/migrate.sh`, which moves the published papers and files of an OCS 2.3.6 archive through OJS 3.4 into OJS 3.5 and prepares the old-address map (checked on a partner's real OCS copy, 1059 papers), and the plugin enables itself at site level on a single-journal install. Version 0.30 reworks the manager's screens by role. Version 0.29 adds card payments through the institution's own LiqPay merchant account (off by default) and the `ConferenceManager::paymentGateways` hook. Version 0.28 syncs dates, venue and format with the TIB Conference plugin both ways. Version 0.27 adds review bidding. Version 0.26 adds promo codes, a seat limit for in-person listeners and a waiting list. Version 0.25 adds a signed QR entry ticket with a check-in page and a personal program. Version 0.24 adds attendance per program session and certificate hours from attended seminars. Reminders need the OJS scheduler (cron), bulk decisions and mailings need the OJS job queue, XLSX needs the PHP `zip` extension. Version 0.23 adds co-organisers and partners of an edition with roles, logos (PNG, JPEG, WebP), order and the co-organiser's payment account, shown on the public page by role and in schema.org markup, and copied with the edition. Version 0.22 checks WCAG 2.1 AA with axe-core on the public pages and the manager's screens in CI and fixes the contrast, labels and focus issues it found. Version 0.21 copies an edition together with its participant categories, tariffs (validity dates moved with the event), payment rules, program rooms and review and abstract book settings, and adds papers, paid invoices and certificates per journal to the site overview with a CSV download. Version 0.20 adds edition reports by journal section, presentation type, participant role, category, institution, country and form with attendance and a CSV download, a scheduler status on the summary page with a warning when cron does not run, and a letter of invitation as a PDF on the institution's letterhead for participants and managers. Version 0.19 adds group invoices (one invoice from an organisation for several participants, a line per participant), invited participants with an invitation letter and zero invoices, and refunds (requested, part or full, with a note, in the accounting export). Version 0.18 added committee voting with comments and totals on the decisions page, a conflict of interest warning by affiliation and two-phase review (abstract, the "abstract accepted, send the full text" decision, full text) with a separate review form for each phase. Version 0.17 added a book of abstracts: one PDF with the abstracts of the accepted papers in the order of the program, the sections or the titles, a title page and an imprint with ISBN and UDC, contents with page numbers, numbered abstracts and an author index, A5 or A4 with mirrored margins. Version 0.16 added old OCS addresses: OCS papers matched with the journal's articles from a CSV, configurable address templates, 301 redirect maps for nginx and Apache, a fallback redirect by the plugin itself and an OCS migration guide ([docs/en/ocs-migration.md](docs/en/ocs-migration.md)). Version 0.15 added a program builder: rooms, sessions, accepted papers dragged into sessions with times computed, warnings for a busy room and a presenter in two sessions at once; the public program by days with a switch to the reader's time zone, stream links only for registered participants, iCal for the program and for one session, a PDF, seminar hours and ECTS, and the time and room of a paper on its article page. Version 0.14 added a first setup wizard that creates an edition with participant categories, tariffs, payment rules and certificate settings from a preset for the type of institution; six presets ship in the package and sites can add their own JSON files in `{files_dir}/conferenceManager/presets/`; role guides in Ukrainian and English are in [docs/en](docs/en/README.md); CI checks six typical institution configurations. Version 0.13 added an isolation test between journals, a site administrator page with all journals, the queue and the scheduled tasks, load profiles (shared hosting, own server, provider) with letters per hour, a fair queue between journals and a quiet period 48 hours before a submission deadline, a static program page of an edition by section and presentation type, and compatibility with the Default, Manuscript and Health Sciences themes. Version 0.12 added retention periods for receipt scans and participant data with a daily task (off by default), a JSON export of everything about a person for the person and for a manager, anonymisation that keeps invoices and issued documents, records that follow an OJS user merge, Google Scholar conference tags and sample privacy notices from the jurisdiction profile. Version 0.11 added the Ukrainian professional development certificate (hours, ECTS credits, learning outcomes, partial qualifications, the institution's legal id) with an English version, a public register of issued documents, revoke and reissue with a new number, an export for the "Vector" platform (off by default), batch issue through the OJS job queue, reviewer thank-you letters and payer organisations with their legal id (a personal tax number only when turned on). Version 0.10 added attendance marks and the import of a Teams, Zoom or Google Meet attendance report with a minute threshold, certificate templates of five kinds with variables and a preview, yearly numbers by series, issue by rules (listeners by attendance, speakers by an accepted paper, absentee authors after publication), A4 landscape PDFs that do not change after issue, a QR code with a public verification page and certificates in the participant's cabinet. Version 0.9 added invoice reissue with the paid amount carried over, publishing only after payment, an accounting export to CSV and XLSX with configurable columns, mailings to participants through the OJS job queue, automatic payment, full text and event reminders, an edition summary, kept versions of the consent text and an audit log viewer. Version 0.8 added editorial decisions 901–904 (accept as an oral, poster, online or absentee presentation) that move the submission to copyediting, put it in the edition's issue and invoice the presenter by the tariff of the type; bulk decisions through the OJS job queue with a letter per author; a presentation type change after the decision that reissues an unpaid invoice; and a conference panel in the submission card. Version 0.7 added payment receipts in the cabinet (PDF/JPG/PNG checked by content, stored outside the web root), a review queue with letters to the payer, an append-only payment journal per edition, a register filter by payment and minor participants with guardian consent. Version 0.6 added payment modes with "category → mode" rules, invoices for listeners and accepted presenters with gapless numbers and payment references, PDF invoices from bank and treasury templates that a journal can edit, the amount in words, part payments and waivers. Version 0.5 added participant categories, the tariff matrix (integer minor units), listener registration, the participant's cabinet, the register of participants with CSV export and cancellation. Version 0.4 added the speaker questionnaire in the submission wizard. Version 0.2 added editions (event types, submission and publication modes, time-zone aware windows, optional OJS issue), the schema of all modules, the Participant and Registration manager user groups and the editions REST API. Version 0.1 contained the foundation: plugin skeleton, idempotent migrations that also run on upgrade (`upgrade.xml`), the institution profile with signers and payment accounts, REST API, CI with install/upgrade tests against real OJS 3.5 on MariaDB and PostgreSQL.
